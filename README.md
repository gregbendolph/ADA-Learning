# Ada System Monitor

Beginner Ada project demonstrating basic system monitoring logic.

### What It Does

Monitors:

Temperature
Voltage
Battery level

Checks whether each value is within a defined safe range and displays warnings when values are outside the limits.

### Concepts

* Ada `Integer` variables
* `if` statements
* Boolean logic (`and` / `or`)
* Comparison operators
* `Put_Line`
* Basic systems monitoring

### Purpose

ADA code Practice
